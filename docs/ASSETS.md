# Asset provenance

PlanetCraft's **runtime** art and audio are generated by the game's own code. The store shell adds a
cinematic intro built from original marketing art, captured gameplay and an original score, plus two
open-font files used only to render the intro video and a neural TTS voice-over.

| Asset type | Source | Where |
|---|---|---|
| Block textures (78 tiles) | Generated at startup from recipes in `data/tiles.json` | `scripts/voxel/texture_factory.gd` |
| Item icons, isometric block icons | Generated at startup from `data/items.json` | `scripts/voxel/texture_factory.gd` |
| UI icons (touch buttons, HUD) | Drawn with vector primitives | `scripts/ui/icon_painter.gd` |
| Creatures, NPCs, rover, ship, tool | Built from box primitives in code | `scripts/world/creature.gd`, `npcs.gd`, `rover.gd`, `world_root.gd`, `scripts/player/player.gd` |
| Sky, terrain lighting, water | Shaders written for this project | `shaders/` |
| Sound effects (28) | Synthesised at startup | `scripts/world/sfx.gd` |
| Music (day/night loops) | Generative synthesis on a background thread | `scripts/world/music.gd` |
| App icon, adaptive icon layers, boot splash | Hand-written SVG rendered by `tools/render_icons.gd` | `art/icon_full.svg`, `art/generated/` |
| Title/end-card key art | Original marketing illustration made with the built-in ImageGen tool | `store/premium/artwork/verdania-key-art.png` (local trailer kit, not committed) |
| Gameplay clips + score | Native Godot viewport captures and an original score (`make-score.py`) from the project trailer kit | `store/premium/planetcraft-assets-and-remotion.zip` (local trailer kit, not committed) |
| Cinematic intro | Composited and encoded by `tools/build_intro.py` (ffmpeg, libtheora/libvorbis) from the key art, clips, score and voice-over; burned-in captions | `art/intro/intro.ogv` |
| English voice-over | Microsoft Edge neural TTS, `en-US-AndrewNeural`, −6% rate, generated with `edge-tts` | inside `art/intro/intro.ogv` |
| F7 Developer brand ident | Supplied by F7 Developer in the brand kit; transcoded to Ogg Theora + Vorbis | `art/intro/f7_brand.ogv` (source: `F7 Brand/Splash Screen Video`) |
| Intro fonts | Outfit SemiBold and DM Sans Medium, SIL Open Font License 1.1, from the trailer kit; rendered into the video only | `video/public/*.woff2` inside the trailer zip |
| Font in-game | Godot's built-in default font (Open Sans, OFL 1.1) | Engine |

All of the above except the fonts and the TTS performance are original F7 Developer work covered by
the repository's MIT licence. The key art is an original illustration, not a screenshot; the intro
gameplay clips are real captures from the game.

**Voice-over note:** the intro VO is a generated placeholder. Microsoft Edge's consumer TTS endpoint
does not grant the same commercial redistribution rights as Azure Speech. Before a commercial Play
Store release, replace the VO with a licensed recording (or an Azure/ElevenLabs commercial account)
and rebuild `art/intro/intro.ogv` with `tools/build_intro.py`.

Note: a Blender MCP connection was configured on the development machine (`.kiro/settings/mcp.json`)
but no Blender-made assets are included. Every 3D model is procedural.
