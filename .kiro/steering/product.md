# Product: PlanetCraft: Galactic Survival

PlanetCraft is an original, fully offline 3D voxel sandbox for Android. The player
crash-lands on an alien world, survives, mines, builds a colony, automates
production, travels between planets and terraforms them.

## Pillars
- **Freedom to build:** every block can be mined or placed; structures are player-made.
- **Planets that react:** mining pollutes, terraforming adds atmosphere, water and life
  (the "Planet Evolution" mechanic). Changes are saved per planet.
- **Exploration with surprises:** alien biomes, crystal caves, precursor ruins, events.
- **Long progression:** tiered tools, machines, ships and planets unlock over many hours.

## Hard constraints
- Offline only. No server, no network calls, no paid APIs, no ads SDK, no analytics.
- Original identity. Do not copy names, textures, sounds or UI from Minecraft,
  No Man's Sky, Astroneer or any other game. All textures are generated by our own code.
- Target: mid-range Android (reference device: Redmi Note 11, Snapdragon 680 "bengal",
  Adreno 610, 6 GB RAM, Android 13). 30 FPS minimum, 60 FPS where the device allows.
- Touch-first controls; keyboard and mouse supported for desktop testing.

## Honesty rule for docs and submissions
Only describe features that exist in the code and were tested. Planned work goes in
`docs/ROADMAP.md` and is labelled as planned. Never claim test results that were not run.
